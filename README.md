# jx3d-paizhuan

Jiangxia Sanlu resettlement area (phase II) masonry arrangement 3D viewer.

- /index.html        : entry page (two models)
- /s5/index.html     : kindergarten S5 masonry arrangement
- /zhuzhai/index.html: residential building masonry arrangement

Static site, no backend. three.js r160 bundled locally (no CDN).
Assets generated from Revit 2024 models via IFC export -> Blender -> glTF (Draco).
